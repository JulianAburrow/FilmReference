# 🎬 FilmReference Application

FilmReference is a Blazor Server application designed to manage and explore films, genres, studios, and people in a clean, responsive UI.  
It leverages **MudBlazor** for modern components, **Entity Framework Core** for efficient data access, and follows best practices for scalability and maintainability.

---

## ✨ Features

- **Film Management**
  - Create, edit, delete, and view films
  - Associate films with genres and studios
- **Genre & Studio Views**
  - Dedicated pages for genres and studios
  - Inline film listings with responsive card layouts
- **Responsive UI**
  - Built with MudBlazor’s grid system
  - Equal-height cards for consistent presentation
- **Reusable Components**
  - `FilmComponent`, `StudioComponent`, `PersonComponent`
  - Centralized `ViewImageComponent` for consistent image rendering
- **Database Integration**
  - Optimized queries for speed and scalability

---

## 🛠️ Tech Stack

- **Frontend:** Blazor WebAssembly
- **UI Framework:** [MudBlazor](https://mudblazor.com/)
- **Backend/Data:** Entity Framework Core
- **Language:** C# / .NET
- **Database:** SQL Server
